# SynaptiLab: How Synapses Become Short-Term Memory

## Project Title

SynaptiLab: How Synapses Become Short-Term Memory

## Central Claim

> A Hebbian synaptic update can store a recently observed association in connection strengths, allowing the association to be recalled after the original input disappears, while decay and interference limit how long that memory remains reliable.

This is an educational claim about the planned simplified model, not a claim that the project fully implements BDH.

## Target Audience

Students and technically curious learners who understand basic neural-network concepts but may not understand synaptic plasticity or BDH.

## Learning Objectives

Learners should be able to:

1. Explain synaptic plasticity.
2. Explain Hebbian-like learning.
3. Describe how changing synaptic state can encode temporary information.
4. Demonstrate memory formation through an experiment.
5. Demonstrate memory decay.
6. Explain interference.
7. Connect the simplified mechanism to BDH.
8. Identify at least one limitation of the simplified model.

## Planned Experiments

1. Plasticity OFF vs ON
2. Memory decay over time
3. Repeated learning
4. Interference between associations
5. Recall after delay

## Educational Journey

Question -> Interaction -> Observation -> Equation -> Experiment -> BDH connection -> Limitation -> Learner challenge

## Scientific Integrity

The project will distinguish clearly between:

- Research-backed claims
- Educational simplifications
- Our own experiments
- Actual BDH mechanisms

The educational model, its mathematics, and the research literature about BDH must not be presented as interchangeable.

## Scope for This Setup Milestone

This milestone establishes structure, configuration, documentation, placeholders, and workflow. It does not implement the SynapticMemory algorithm, scientific experiments, complete Streamlit application, or BDH mechanism.
